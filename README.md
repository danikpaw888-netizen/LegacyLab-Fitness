# LegacyLab Fitness

Публичная демонстрация премиального фитнес-клуба: https://legacylab-fitness.danikpaw888.workers.dev

## Возможности

21 маршрут с серверным HTML: главная, клуб и галерея, шесть направлений, тренеры и четыре профиля, расписание, пять тарифов, запись, демо-кабинет, контакты и документы. Работают фильтры с URL, выбор тарифа, ошибки рядом с полями, подтверждение, защита от повторной отправки, локальное сохранение, история и отмена. Доступны мобильное меню, FAQ и увеличение фотографий.

Это демонстрация: клуб, контакты, профили, опыт, отзывы, цены и расписание вымышлены. Фотографии созданы ИИ. Записи сохраняются только в localStorage этого браузера, не отправляются администратору. Авторизации, оплаты, CRM, серверной базы и синхронизации устройств нет. Не вводите чувствительные данные. На общем компьютере кабинет доступен другим пользователям того же браузерного профиля.

## Запуск и проверки

Node.js 24:

```sh
npm ci
npm run check
npm run dev
```

`npm run check` проверяет синтаксис и неопределённые ссылки, тесты логики, production-сборку и маршруты реального Worker в Miniflare. Дата совместимости Cloudflare: 2026-10-25. React 19, React Router 7, JavaScript ESM, esbuild. Изображения WebP и ресурсы встроены в Worker. База, R2 и платные ресурсы не требуются.

## Изменение контента

- `src/data.js`: конфигурация, направления, тренеры, тарифы (цены в копейках), FAQ и расписание.
- `src/domain.js`: валидация, запись, отмена и хранилище.
- `src/ui.js`: общие элементы, меню, галерея, шапка и подвал.
- `src/pages.js`: основные страницы, контакты и документы.
- `src/schedule.js`, `src/booking.js`, `src/account.js`: сценарии расписания, записи и кабинета.
- `src/styles.css`: дизайн-токены и адаптивность.
- `src/meta.js`: заголовки, описания и sitemap.
- `public/images`: фотографии; заменяйте обычную и `-sm.webp` версии, используя разрешённые изображения.
- `public/favicon.svg`, `public/og.png`: иконка и превью ссылки.

После редактирования запускайте проверки и публикацию. Панель администратора не предусмотрена: контент редактируется в исходниках.

## Публикация

```sh
npx wrangler login
npm run deploy
```

Подготовлен GitHub Actions для проверок. Workflow публикации требует секрет `CLOUDFLARE_API_TOKEN` в GitHub Environment `production`. Он должен иметь минимальные права Workers Scripts Write для нужного аккаунта. Account ID в конфигурации не является секретом. Пока секрет не добавлен, автоматическая публикация пропускается. PR не меняет production; preview-развёртывания не настроены. Платные подписки не активировались.

## Правила и ограничения

Неделя расписания формируется в Asia/Oral (UTC+5). Запись — на ближайшие 90 дней; отмена — минимум за два часа. Места учитываются только в этом браузере, это не реальная атомарная бронь между устройствами или одновременно открытыми вкладками. Выбранный тариф не является оплаченным абонементом.

Для удаления данных используйте действие в кабинете или очистку данных сайта в браузере. Серверной резервной копии нет. Для собственного экспорта можно сохранить localStorage `legacylab-fitness:v1` через инструменты браузера; он содержит введённые контакты, не публикуйте его.

Первоначальная Windows-среда стала недоступна до завершения выгрузки. Текущий редактируемый React-проект восстановлен из опубликованной сборки, разделён на модули и проверен заново. Исходные TypeScript-типы и часть исходных локальных имён не восстановлены. Это JavaScript-проект, а не копия утраченных TypeScript-файлов. Внешний вид и сценарии сохранены; vendor-код заново подключается через npm.

Перед реальным запуском нужны настоящие реквизиты, контакты, юридические документы, серверная авторизация и хранение, атомарная бронь мест и обработка заявок. Lighthouse не измерялся; вымышленные оценки не приводятся.
